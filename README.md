# 🚀 Smart Task Manager (Aplikasi Pengelola Tugas)

Aplikasi To-Do List responsif dan kaya fitur yang dirancang untuk membantu pengguna mengelola tugas harian dengan efisien. Dibangun dengan fokus pada tampilan yang bersih, interaksi yang mulus, dan penyimpanan data otomatis.

## ✨ Fitur Utama

* **Penyimpanan Otomatis:** Menggunakan `Local Storage` sehingga daftar tugasmu tidak hilang meskipun browser ditutup atau di-refresh.
* **Filter Cerdas:** Saring tugas berdasarkan status "Semua" atau "Belum Selesai".
* **Level Prioritas:** Kategorikan tugas berdasarkan Prioritas (High, Medium, Low) dengan kode warna yang dinamis.
* **UI Interaktif:** Animasi halus saat menambah, menghapus, atau menandai tugas.
* **Desain Responsif:** Tampilan optimal untuk diakses lewat Laptop, Tablet, maupun HP.
* **Modern Styling:** Dibangun menggunakan Tailwind CSS untuk tampilan yang bersih dan profesional.

## 🛠️ Teknologi yang Digunakan

* **HTML5:** Struktur semantik halaman.
* **Tailwind CSS:** Untuk styling yang cepat dan responsif.
* **Vanilla JavaScript (ES6+):** Menangani logika DOM, Event Listeners, dan Manajemen Data.
* **Vercel:** Platform deployment (server).
